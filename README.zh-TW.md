### 03. [金融資產避險能力實證分析](https://github.com/yo1616/Financial-Asset-Hedging-Analysis)

**金融資料分析 · 計量經濟 · 統計建模**

本專案透過歷史金融市場資料，研究 S&P 500 與黃金、美國公債 ETF、瑞士法郎及比特幣等資產之間的關係，分析不同資產在一般市場與危機期間可能具有的避險特性。

研究運用相關分析、迴歸模型及危機期間交互作用項，探討金融資產在不同市場條件下的表現。

**我的貢獻**

- 使用 Python 蒐集、清理及整理歷史金融市場資料。
- 實作相關分析、OLS 迴歸、假設檢定及危機期間交互作用模型。
- 製作統計視覺化圖表，比較不同市場環境下的資產關係。
- 解讀實證結果，評估各類資產可能具有的避險特性。

**使用技術：** `Python` `pandas` `statsmodels` `yfinance` `Data Visualization`

### 04. [統計學習與深度學習專案](https://github.com/yo1616/Statistical-Learning-Projects)

**機器學習 · 自然語言處理 · 預測分析**

本專案包含兩項應用型機器學習研究，分別針對商品價格預測與職缺人才匹配問題，運用資料前處理、特徵工程及模型評估建立預測流程。

**商品價格預測（Product Price Prediction）**

- 使用文字前處理、字元層級 n-gram 與正則化迴歸建立商品價格預測模型。
- 透過特徵工程與模型評估，比較預測效果及計算效率。

**職缺人才匹配（Job–Talent Matching）**

- 利用職缺描述、履歷文字與結構化條件建立分類模型。
- 運用 TF-IDF、One-hot Encoding 及特徵工程表示匹配條件。
- 比較 Logistic Regression 與 LightGBM，透過模型評估及分類門檻調整改善效果。
- 將驗證集 F1 Score 從 **0.29 提升至 0.57**。

**使用技術：** `Python` `scikit-learn` `LightGBM` `TF-IDF` `Feature Engineering`
